# ИС «Помогатор» — автоматизация склада торговой сети

**Помогатор** — это информационная система для автоматизации учёта и управления запасами на складе.  
Проект разработан в рамках курсовой работы по дисциплине «Технология разработки программного обеспечения».

---

## Основные функции системы

- Приёмка товара через ТСД (терминал сбора данных) с автоматическим предложением ячейки
- Адресное хранение и контроль остатков в реальном времени
- Отгрузка товара с построением маршрута сборки по принципу FEFO
- Автоматическое пополнение запасов при достижении точки заказа (остаток <= 10)
- Циклическая инвентаризация без остановки склада
- Ролевая модель доступа: кладовщик, менеджер, руководитель, администратор, магазин
- Формирование отчётов (остатки, движения, просрочка, дефицит)
